Spectre Variant 1 – Bounds Check Bypass

Microarchitectural Security Assignment

Non-Technical Summary

Spectre Variant 1 is a CPU vulnerability that tricks the processor into executing instructions it should not normally run. Even though these “speculative” operations are later cancelled, they leave behind tiny traces inside the processor’s cache. By measuring how fast the cache responds, an attacker can recover secret data such as passwords or sensitive memory values. This page contains a full attack demonstration recorded in a safe, controlled virtual machine and an academic report explaining how the attack works.
